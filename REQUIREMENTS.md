# Payment Bot — Требования

## Контекст

Зарплата делится на два периода:
- **Аванс**: 1–15 число месяца
- **Остаток**: 16–конец месяца

Расчёт: `дневная_ставка = зарплата / рабочих_дней_в_месяце`. Праздники и выходные не считаются рабочими днями (данные: isdayoff.ru).

---

## Функциональные требования

### Расчёт выплат
- Бот рассчитывает аванс и остаток зарплаты за текущий месяц
- Показывает количество рабочих дней в каждом периоде
- В **групповых чатах** — только проценты (без сумм)
- В **личных сообщениях** — суммы в рублях + проценты

### Хранение зарплаты пользователя
- В ЛС бот запрашивает зарплату при первом обращении и сохраняет её
- Зарплата привязана к `telegram_user_id`
- Пользователь может изменить зарплату в любой момент
- При каждом расчёте используется сохранённая зарплата

### Кэширование производственного календаря
- Данные о рабочих днях кэшируются в БД после первого запроса к isdayoff.ru
- Повторные запросы за тот же месяц берутся из БД
- Кэш хранится бессрочно (производственный календарь не меняется)

## Команды

| Команда | Где работает | Описание |
|---|---|---|
| `/start` | ЛС, группа | Приветствие и инструкция |
| `/calc [месяц] [год]` | ЛС, группа | Расчёт выплат за текущий (или указанный) месяц |
| `/salary` | только ЛС | Показать текущую зарплату |
| `/salary <сумма>` | только ЛС | Установить или изменить зарплату |
| `/help` | ЛС, группа | Справка по командам |

**В групповом чате** — команды `/salary` и `/salary <сумма>` игнорируются (бот не отвечает).

## Схема базы данных

### `calendar_cache`
```
year        INTEGER  — год
month       INTEGER  — месяц (1–12)
days_data   TEXT     — строка из 0/1 от isdayoff.ru (длина = кол-во дней в месяце)
created_at  TIMESTAMP
PRIMARY KEY (year, month)
```

### `users`
```
telegram_id  BIGINT   — Telegram user ID
salary       NUMERIC  — ежемесячная зарплата
updated_at   TIMESTAMP
PRIMARY KEY (telegram_id)
```

## Алгоритм работы

### Личные сообщения (ЛС)

#### Первый визит (`/start` или любое сообщение)
```
1. Бот проверяет users.salary по telegram_id
2. Зарплата не найдена →
       "Привет! Введите вашу ежемесячную зарплату (например: 1000000)"
3. Зарплата найдена →
       "Привет! Ваша зарплата: 1 000 000 ₽. Введите /calc для расчёта или /salary <сумма> для изменения."
```

#### Пользователь вводит число (без команды)
```
1. Если зарплата ещё не установлена — трактуем как ввод зарплаты:
       a. Сохраняем в users
       b. Сразу делаем расчёт и отвечаем с суммами
2. Если зарплата уже есть — предлагаем уточнение:
       "Вы хотите обновить зарплату до 120 000 ₽? [Да / Нет]"
       Да → обновляем, делаем расчёт
       Нет → делаем расчёт по старой зарплате
```

#### `/calc`
```
1. Получить зарплату из users по telegram_id
2. Зарплата не найдена → "Сначала укажите зарплату: /salary <сумма>"
3. Зарплата найдена:
       a. Проверить calendar_cache для (текущий год, текущий месяц)
       b. Кэш есть → читать из БД
       c. Кэша нет → запросить isdayoff.ru → сохранить в calendar_cache
       d. Рассчитать аванс и остаток
       e. Ответить с суммами в ₽ и процентами
```

#### `/salary` (без аргумента)
```
1. Зарплата не установлена → "Зарплата не указана. Введите /salary <сумма>"
2. Зарплата установлена → "Ваша зарплата: 100 000 ₽ (обновлено 15.05.2026)"
```

#### `/salary <сумма>`
```
1. Валидировать: сумма > 0, число
2. Сохранить в users (upsert)
3. Ответить: "Зарплата обновлена: 120 000 ₽"
4. Сразу показать расчёт за текущий месяц
```

---

### Групповой чат

#### `/calc`
```
1. Получить производственный календарь (кэш → isdayoff.ru)
2. Рассчитать доли периодов
3. Ответить только процентами — без сумм:

   Расчёт за май 2026:
   Аванс (1–15 мая):    11 раб. дней — 46.8%
   Остаток (16–31 мая): 13 раб. дней — 53.2%
```

#### `/salary`, `/salary <сумма>`
```
Игнорировать — бот не отвечает.
```

#### `/start`, `/help`
```
Показать краткую справку без упоминания личных данных.
```

## Нефункциональные требования

- **Язык**: Go
- **Архитектура**: Clean Architecture
- **Telegram-библиотека**: go-telegram-bot-api/v5
- **База данных**: PostgreSQL
- **Конфигурация**: переменные окружения (`TELEGRAM_TOKEN`, `DATABASE_URL`)
- **Таймаут** запроса к isdayoff.ru: 10 секунд
- Бот не хранит историю запросов — только зарплату и кэш календаря
